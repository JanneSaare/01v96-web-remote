01V96 Remote

Scales were measured on one 01V96 V2 (see docs/PROTOCOL.md). A LOW/HIGH band is drawn as a bell, a shelf or an HPF/LPF depending on its Q value; the roll-off slope of HPF/LPF is approximate. Dimmed values are not yet known: they are read from the console at server start and appear once you touch them.
